# Amazon (Bar Raiser)

Questions map to the Leadership Principles. Every answer needs a metric and "I".

| Theme | What they test | Story # |
|-------|----------------|---------|
| Ownership | Taking responsibility, driving results | |
| Disagreement | Respectful, data-driven pushback, then commit | |
| Decisions | Judgment with limited data, quick calls, trade-offs | |
| Learning | Failure and what changed after | |
| Trust and risk | Building credibility, calculated risks | |
| Growth | Mentoring, improving processes | |
| Priorities | Competing demands, stakeholder communication | |
| Standards | Raising the bar, challenging the status quo | |
| Customers and pressure | Customer obsession, delivering under pressure | |
| Escalation | Raising issues early | |

Practice prompts:
- Tell me about a time you took ownership beyond your role.
- Tell me about a time you disagreed with your manager or team.
- Tell me about a time you decided with incomplete data.
- Tell me about a time you failed.
- Tell me about a time you raised the bar on quality.
- Tell me about a time you escalated an issue early.
