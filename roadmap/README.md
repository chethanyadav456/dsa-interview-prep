# DSA Roadmap

Pattern-based, company-wise DSA roadmap. Source: [Company-wise DSA patterns](https://jugaldb.substack.com/p/company-wise-dsa-patterns). All problem links point to LeetCode and were checked for existence.

## Files

| File | What it is |
|------|-----------|
| [60-day-plan.md](60-day-plan.md) | Day-by-day plan in 6 phases with checkboxes |
| [patterns.md](patterns.md) | 22 core patterns, grouped problems, master checklist |
| [companies.md](companies.md) | Amazon, Google, Meta, Netflix, Uber, Airbnb, Microsoft, Apple: core patterns and curated lists |
| [pattern-cheatsheet.md](pattern-cheatsheet.md) | Fill-in table of trigger phrases and go-to problems |

## How to use

1. Pick your target companies and note their core patterns in [companies.md](companies.md).
2. Follow [60-day-plan.md](60-day-plan.md), 60-90 min a day. Tick the box when a problem is solved.
3. Save each solution under `dsa/<folder>/NNN-problem-name.<ext>` (folder per [patterns.md](patterns.md)), copy `templates/problem.md` for the write-up, and add a row to the main README log.
4. After each phase, fill the matching rows of [pattern-cheatsheet.md](pattern-cheatsheet.md).
5. Days 56-57 are company simulations: pick a company and solve 4 of its problems mixing patterns.
